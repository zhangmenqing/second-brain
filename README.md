## 结构（PARA 方法）
- **Inbox/** — 收集箱：临时捕捉的想法、碎片，待分类
- **Projects/** — 项目：有明确目标和截止的事
- **Areas/** — 领域：需长期维护的责任区（健康/财务/工作…）
- **Resources/** — 资源：感兴趣的主题资料库
- **Archives/** — 归档：已完成或暂停的项目与领域

## 使用约定
- 新想法先丢 **Inbox**，定期整理到其余区
- 笔记用 Markdown；文件名用 `日期-主题` 或清晰标题
- 大文件（图片/视频/安装包）**不进 git**，用外链或单独存储
- 改完记得 `commit` + `push`

## 同步（GitHub）
- 日常流程：`git pull` → 改 → `git add -A && git commit -m "..."` → `git push`
- 两台电脑都 clone 到 `E:\workbench\`，路径一致即可无缝衔接
